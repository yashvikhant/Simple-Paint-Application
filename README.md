# Simple-Paint-Application #
It is a simple paint app made using JavaScript and HTML5. No other libraries are used.
# Description: #
* Simple Paint App using HTML5 Canvas Element that lets users to draw Rectangles on the canvas by clicking & dragging the mouse like in Windows Paint App
* Size of Rectangles should depend on how much the user drags the mouse.
* Automatically fills each rectangle with a different color
* Added a clear / reset button that clears the canvas
* Added feature to drag Rectangles using Mouse
* If the mouse is being dragged on an existing Rectangle, drag the same or else create a new one.
* Double clicking on a Rectangle should delete the same.
